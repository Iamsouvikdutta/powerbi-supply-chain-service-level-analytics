# Dataset Description

## Domain

Supply Chain Analytics

## Industry

FMCG (Fast-Moving Consumer Goods)

## Business Context

AtliQ Mart is a growing FMCG organization focused on improving customer service levels and operational efficiency. The company aims to monitor delivery performance and identify opportunities to improve fulfillment processes.

## Project Objective

Analyze supply chain performance using service-level KPIs to identify bottlenecks impacting customer satisfaction and operational effectiveness.

## Key Metrics Used

- OTIF (On Time In Full)
- OT (On Time Delivery)
- IF (In Full Delivery)
- LIFR (Line Fill Rate)
- VOFR (Volume Fill Rate)

## Analysis Dimensions

The dashboard analyzes performance across:

- Customers
- Products
- Cities
- Order Metrics
- Time Periods

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
